# Newly Added Admin APIs

The following APIs have been added to complete the Admin CRUD operations:

### `PUT /admin/staff/{id}`
Update a staff member. Matches the `Staff` creation object, but all fields are optional.

### `DELETE /admin/staff/{id}`
Delete a staff member.

### `PUT /admin/services/{id}`
Update a service. Matches the `Service` creation object, but all fields are optional.

### `DELETE /admin/services/{id}`
Delete a service.

### `DELETE /admin/bookings/{id}`
Delete an appointment (booking).
